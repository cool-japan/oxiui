# Curated crash regressions

Unlike `fuzz/corpus/` and `fuzz/artifacts/` (both gitignored — ephemeral, can
be regenerated by re-running the fuzzer), this directory is **not**
gitignored. It holds a hand-picked copy of specific crash inputs that are
cited by name from source comments / `TODO.md` and therefore need to survive
a fresh clone.

Reproduce a crash directly with cargo-fuzz:

```sh
cargo +nightly fuzz run fuzz_fill_polygon fuzz/regressions/fuzz_fill_polygon/crash-75bd14507aaf06979c7bdbc7479e667dda9c14ef
cargo +nightly fuzz run fuzz_bezier_flatten fuzz/regressions/fuzz_bezier_flatten/crash-bc9e57a5522d24fc0508b9f3935bd9ab75686094
```

## `fuzz_fill_polygon` / crash-75bd14507aaf06979c7bdbc7479e667dda9c14ef

25 bytes, decoded per `fuzz_fill_polygon.rs`'s `decode_points` (two
little-endian `f32`s per 8-byte chunk, non-finite points dropped) into a
3-point triangle:

| point | x | y |
|---|---|---|
| 0 | `-0.49999240040779114` | `0.0000109206876004464` |
| 1 | `0.0` | `-1.7014635547491816e+38` |
| 2 | `0.0` | `3.0673052914172136e-38` |

Point 1's `y` is finite but so large that `y as i32` (Rust's saturating
float-to-int cast) collapses to `i32::MIN`. `scanline.rs`'s fast-forward loop
then computes `y_start - edge_y_start` with `y_start` clamped to
`[0, framebuffer_height]` and `edge_y_start` unclamped — `0 - i32::MIN`
panics with `attempt to subtract with overflow`. See the crate's `TODO.md`
"Key Gaps" entry for `oxiui-render-soft`.

## `fuzz_bezier_flatten` / crash-bc9e57a5522d24fc0508b9f3935bd9ab75686094

29 bytes, decoded per `fuzz_bezier_flatten.rs`'s `read_finite_f32s::<7>` into
the quadratic-bezier argument list `(p0, p1, p2, tolerance)`:

| param | value |
|---|---|
| `p0` | `(0.0, -2.352733552539301e+38)` |
| `p1` | `(-7.534538992064535e-14, -7.534538992064535e-14)` |
| `p2` | `(9.766966218436115e-40, -4.3966973934714695e-18)` |
| `tolerance` | `-4.408238217377809e-18` |

All seven values are individually finite. `path.rs`'s private `mid(a, b)`
helper computes `(a.0 + b.0) * 0.5`; De Casteljau subdivision of `p0`/`p1`
repeatedly re-adds coordinates derived from `p0.1 = -2.35e38` to themselves,
and the pre-halving sum overflows `f32::MIN` (`-3.4028235e38`) to
`-Infinity`. The chord-deviation base-case comparison against a non-finite
value is always `false`, so `flatten_quad_bezier`'s recursion never
terminates. See the crate's `TODO.md` "Key Gaps" entry for
`oxiui-render-soft`.
